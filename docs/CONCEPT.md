# New Site

Create a new site in www/ with the same content as before but not requiring PHP or any server-side processing.
The new site should be a static HTML version of the existing site, preserving the layout, styles, and content. Ensure that all links, images, and resources are correctly referenced and functional in the new static version.

Create a repo called "site-unfolding.pt" on GH cawoodm with a GH action to publish to GitHub Pages when main is pushed.

Update (v3): the site is built with Hugo (see BUILD.md). The old script and Vite build are gone.
